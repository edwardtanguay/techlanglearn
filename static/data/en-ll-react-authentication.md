## What is user authentication?, 6:27, 2025-03-17

- three tests
  - knowledge test
    - user knows something
    - e.g. password or pin or security question: mother's maiden name
  - ownership test
    - user has something
    - e.g. e-mail address, mobile number, OTP fob, OPT app (One-Time Password)
    - relies on knowledge-based strategies
    - physical devices can be stolen or lost
- two-factor authentication: knowledge and ownership
  - biological test
  - facial recognition
  - fingerprint scanners
  - eye scanners
